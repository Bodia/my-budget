# 💰 My Budget — Local-First Фінансовий Портал & Розумна Аналітика

Сучасний, приватний та швидкий веб-додаток для детального аналізу фінансів, автоматичного імпорту виписок **Monobank** та **Toshl Finance**, оптимізації витрат і пошуку точок економії.

Побудований за концепцією **Local-First**: усі дані обробляються та зберігаються виключно у браузері користувача (`IndexedDB`). Жоден файл та жодна транзакція не надсилаються на зовнішні сервери.

---

## ✨ Основні можливості

### 1. 📥 Розумний конвеєр імпорту та дедуплікація
- **Автоматичне розпізнавання виписок**: підтримуються файли `.xlsx`, `.xls` та `.csv`.
- **Monobank Adapter**: парсинг українського формату дат (`DD.MM.YYYY HH:mm:ss`), сум, комісій, кешбеку та словник **MCC-кодів** (Супермаркети, Кафе, АЗС, Таксі, Аптеки тощо).
- **Toshl Finance Adapter**: підтримка експорту Toshl з категоріями, тегами та мультивалютністю.
- **Deduplication Engine**: детермінований розрахунок хешу `SHA256(дата + сума + опис + рахунок)`. Повторне завантаження виписок не створює дублікатів.
- **Попередній перегляд (Preview Modal)**: підсумок перед записом (всього / нові / дублікати).

### 2. 📊 Візуалізації у стилі Ant Design (`@ant-design/plots` / AntV G2)
- **Interactive Donut Chart**: структура витрат за категоріями з процентним розподілом та інтерактивним виділенням.
- **Cashflow Column Chart**: помісячне зіставлення доходів і витрат зі згрупованими стовпчиками.
- **Top Merchants Bar Chart**: рейтинг контрагентів з найбільшими сумами списань (Сільпо, ОККО, Нова Пошта тощо).
- **Budget Control Gauges**: прогрес-бари лімітів категорій зі зміною кольорів (смарагдовий / бурштиновий / багряний).
- **Activity Heatmap (365 днів)**: річна теплова карта витрат по днях у стилі GitHub-активності.

### 3. 💡 Модуль «Розумна економія» (Smart Savings Engine)
- **Детектор регулярних підписок**: виявлення щомісячних фіксованих платежів (Netflix, Spotify, Apple, YouTube, Megogo, Kyivstar, спортзал) та розрахунок щорічних витрат.
- **Ефект лате (Мікровитрати)**: агрегація дрібних витрат (<180 ₴: кава, перекуси, дрібниці) та підрахунок потенціалу заощаджень.
- **Детектор аномальних сплесків**: виявлення різкого зростання витрат на заклади та доставку їжі відносно домашніх продуктів.
- **Аналіз правила 50/30/20**: перевірка балансу «Потреби / Бажання / Заощадження».

### 4. 🔒 Конфіденційність та керування даними
- **100% Client-Side**: збереження в IndexedDB через `Dexie.js`.
- **Експорт / Імпорт бекапів**: вивантаження повної бази в `.json` та відновлення в 1 клік.
- **Демо-режим**: швидке завантаження ~400 реалістичних операцій за 12 місяців для тестування.

## 🛠️ Стек технологій

- **Frontend**: React 19, TypeScript, Vite
- **Сховище**: `IndexedDB` через `Dexie.js` + `dexie-react-hooks`
- **Парсинг файлів**: `xlsx` (SheetJS), `papaparse`
- **Графіки та діаграми**: `@ant-design/plots` (AntV G2), `@ant-design/icons`, `lucide-react`
- **Дизайн**: Ant Design inspired CSS Tokens (темна та світла теми, скляні картки, плавні анімації)
- **Тестування**: `vitest`

## 🚀 Швидкий старт

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск локального сервера розробки
```bash
npm run dev
```
Відкрийте у браузері: [http://localhost:5173/](http://localhost:5173/)

### 3. Збірка для продакшну
```bash
npm run build
```

### 4. Запуск тестів
```bash
npm test
```
